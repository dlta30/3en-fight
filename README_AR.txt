3eN Fight Scanner PRO — Render Web Starter

هذه نسخة ويب أولية قابلة للنشر على Render، وليست أداة تفحص جهاز اللاعب تلقائيًا.
المتصفح لا يستطيع الوصول إلى مجلدات Windows/FiveM المحلية دون برنامج محلي مستقل.
تقبل هذه النسخة رفع ملفات يختار المستخدم مشاركتها يدويًا، ثم تفحص أسماء الملفات وتحسب SHA-256 وتصدر CSV.
الأسماء المطابقة مؤشرات للمراجعة وليست إثباتًا على الغش.

النشر:
1) ارفع محتويات هذا المجلد إلى مستودع GitHub.
2) Render > New + > Web Service، ثم اربط المستودع.
3) Build Command: pip install -r requirements.txt
4) Start Command: gunicorn app:app
5) أضف ADMIN_PASSWORD بكلمة مرور قوية و APP_SECRET بسلسلة عشوائية.
6) انشر الخدمة.

مهم: تخزين النسخة التجريبية محلي داخل خدمة Render قد لا يستمر بعد إعادة التشغيل. للاستخدام الفعلي تحتاج قاعدة بيانات وتخزين دائم. لا ترفع ملفات شخصية أو حساسة.
